## המלכודת המרכזית — כונן `Z:` שבור

המכונה הזו מריצה את הפרויקט מ‑`Z:`, שהוא mount של SSHFS על אותה מערכת קבצים. **הדרייבר
של Windows מחזיר `EPERM` במקום `EEXIST` הסטנדרטי** כשמשהו קורא `mkdir` על תיקייה שכבר
קיימת. זה שובר:

- `npm install` / `npm test` / `npm run lint` / `npm run web` מ‑`Z:`
- כלי ה‑`Edit` של Claude Code ספציפית — `Write` ופקודות shell פשוטות (`cp`, `sed`)
  **עובדות תקין**

בנוסף, ה‑mount עצמו יכול **ליפול לגמרי תחת עומס** (נצפה מספר פעמים, ככל הנראה תופעת לוואי
של פתיחת/סגירת כמה SSH tunnels ברצף) — כשזה קורה, אפילו `cd` לפרויקט נכשל עד שה‑mount
מתחבר מחדש לבד או מחוברר מחדש.

## דרך העקיפה — SSH ישיר לאותו host

```bash
ssh aviv@100.76.172.46
cd shared_disk/Cursor_apps/Eps_Evaluation
```

אותה מערכת קבצים בדיוק, אותם קבצים, אבל סמנטיקת `mkdir` תקינה של לינוקס.
`npm install`/`test`/`lint`/`build`/`web` **עובדים שם נורמלית**, בלי תלות במצב `Z:`.

**להרצת טסטים/lint/build בפועל:**
```bash
ssh -o BatchMode=yes aviv@100.76.172.46 'cd shared_disk/Cursor_apps/Eps_Evaluation && npx vitest run'
ssh -o BatchMode=yes aviv@100.76.172.46 'cd shared_disk/Cursor_apps/Eps_Evaluation && npx eslint .'
ssh -o BatchMode=yes aviv@100.76.172.46 'cd shared_disk/Cursor_apps/Eps_Evaluation && npx tsc -p tsconfig.json'
```

`.claude/hooks/stop-test-gate.sh`'s `TEST_CMD` **כבר מנותב** דרך אותו hop ב‑SSH (קומיט
`0d6082b`) — ה‑stop-gate מאמת מול הסביבה האמיתית, לא המקומית השבורה.

## לעריכת קבצים כש‑`Edit` נכשל

אם `Edit` נכשל עם `EPERM: operation not permitted, mkdir ...`:

1. כתוב את התוכן המלא ל‑scratchpad עם `Write`
2. `cp` את הקובץ מה‑scratchpad ל‑`Z:` דרך `Bash` (פעולות shell פשוטות על `Z:` עובדות)
3. לחלופין: `sed` in‑place ישירות על `Z:` — עובד, ומהיר יותר לשינויים מכניים קטנים
4. **לתיקון נקודתי בתוך קובץ קיים** (בלי לשכתב את כולו): node -e עם fs.readFileSync/replace/writeFileSync על נתיב עם forward slashes (Z:/Cursor_apps/..., לא backslashes — גם escaping כפול בתוך מחרוזת Bash נשבר ל-ENOENT). זו הדרך שעבדה בפועל לתיקונים חד-שורתיים כמו סדר td.append(...) או ערך CSS בודד, כשלא רצוי לשכתב קובץ שלם מחדש רק בשביל שינוי קטן.
